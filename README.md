# Khairul Azman — Personal Homepage

Minimal academic portfolio, built with plain HTML and CSS. No frameworks, no build step.

## Files

- `index.html` — all content (edit this to update bio, news, publications, etc.)
- `style.css` — styling
- `profile_photo.jpg` — profile picture

## Deploying to GitHub Pages

Push this repo to `azman-i.github.io` (user site) and GitHub Pages serves it automatically:

```bash
git remote add origin https://github.com/azman-i/azman-i.github.io.git
git push -f origin main
```

Then in the repo settings on GitHub: **Settings → Pages → Source: Deploy from a branch → main / (root)**.

No build step needed — GitHub Pages serves `index.html` directly.
